## 仕様書の書式

```
# Mxx 題名

## 目的
（なぜやるか、2〜3行）

## 前提
（前のマイルストーンで何ができているか、読むべき文書）

## 作業
（番号つきの手順）

## 受け入れ条件
（テストやファイルで確かめられる条件だけを書く）

## やらないこと

## 着手前に確認すること
（あなたが決めてはいけないこと、質問すべきこと）
```
