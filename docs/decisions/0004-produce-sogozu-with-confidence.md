# 0004 総合図を確度つきで作る範囲に広げる

**状態：** 決定
**日付：** 2026-09-26（提案）、2026-09-27（承認）
**決めた人：** ユーザー（提案の推奨どおりに承認）
**変更する決定：** 0001「総合図そのものは作らない」「設備機器・天井割のデータ構造は今は作らない」

## 背景

ユーザーから「いまのシステムの発展型で総合図まで描けるようにしたい」との要望があった。
0001 では、総合図に描く梁・設備・機器は構造設計・設備設計・製品選定の結果がないと決まらず、推測で埋めると精密に見えて中身のない図になる、という理由で範囲外としていた。

## 決定（案）

1. 総合図を範囲に入れる。ただし総合図は「図」ではなく**建物モデル**（部材の集まり）の見え方として作る。
2. 建物モデルのすべての部材に**確度**（0 仮定／1 計画／2 設計／3 確定）を持たせ、図面で描き分け、凡例と確度0の割合を紙面に必ず載せる。
3. 部材の配置（配置エンジン）と干渉の調査（調整エンジン）は solver が行う。LLM は翻訳・候補出し・説明に限る。
4. 法規（`solver/law/`）と設計標準（`standards/`）を分け、指摘の重さを分ける。法規の指摘は設計者が許容できない。
5. 構造計算・設備設計はしない点は変えない。確度0の部材は設計の代わりではなく仮置きである。
6. 他社図面（DXF、後に IFC）を取り込み、仮定の部材を置き換える。
7. 最初の対象は基準階の天井伏総合図とし、M15 で一度止めて評価する。

詳細は `docs/system_design_sogozu.md`。

## 検討した選択肢

| 選択肢 | 採らない理由 |
|---|---|
| 0001 のまま、基準データの受け渡しまで | ユーザーの要望に応えられない |
| 確度を持たずに仮配置した総合図を出す | 0001 の懸念（精密に見えて中身がない）がそのまま残る |
| LLM に配置させる | 規定を満たすことを誰も保証できない |
| 他社図面の取り込みだけ（生成しない） | 企画・基本設計の段階では取り込む図面がまだない。仮定で先に成立性を見る価値がある |

## 理由

0001 の懸念の核心は「根拠のないものが、根拠のあるものと見分けられない」ことだった。確度を部材に持たせ、出力器で描き分けと注記を強制すれば、見分けがつく。これにより企画段階の仮定入り総合図と、設計段階の本来の総合図を、同じ仕組みで扱える。

## 影響

- 算定結果（ボリューム・天空率など既存の段）には影響しない。
- `architecture.md` §1（範囲）、§3（フォルダ構成）、§7（図面）、§12（将来の拡張）を改める。
- `CLAUDE.md` の「総合図そのものは作らない」を改める。
- 消防法などの新しい法規の表が必要になり、担当者の確認が前提になる。
- マイルストーン M10〜M20 を追加する（`docs/milestones/README.md`）。

## 承認の内容（`docs/system_design_sogozu.md` §14）

ユーザーは「進めてください」として、推奨どおりに承認した。

| No | 論点 | 決定 |
|---|---|---|
| 1 | 0001「総合図そのものは作らない」 | 改める。確度つきで作る |
| 2 | 確度の段階 | 4段階（0 仮定／1 計画／2 設計／3 確定） |
| 3 | 最初の対象 | 基準階の天井伏総合図（M15 で一度止めて評価） |
