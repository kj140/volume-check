# 0006 日影規制の常時注記・高度地区と地区計画の未確認・出ない注記の修正

**状態：** 決定
**日付：** 2026-09-27
**決めた人：** ユーザー（M02 完了報告の提案 1〜3 を推奨どおりに承認）

## 背景

M02 の完了報告で3点を提案した（`docs/decisions/0005` 末尾）。

## 決定

| No | 決定 | 実装 |
|---|---|---|
| 1 | 日影規制が未実装であることを、日影規制の対象区域の指定の有無にかかわらず注記する。向きは「実際より大きく出る」 | `solver/__init__.py` の注記。指定ありのときは従来の【要注意】の注記、なしのときは新しい注記（どちらか一方） |
| 2 | 高度地区・地区計画が算定に入っていないことを、未考慮事項として出す。不明なら「未確認」、入力があっても「算定に未反映」 | `solver/volume/stage.py` の `_fact_gaps`。向きは unknown |
| 3 | 出ることのなかった注記2つを直す | 建蔽率の絞り込みの注記を、絞り込み量が決まった後に出す。北側斜線の到達しない分岐は削除（同じ内容は適用規定の「北側斜線：適用なし（…）」に既に出ている） |

## 実装上の判断（ユーザーの承認と違う点）

- **1 は「住居系の案」ではなく全用途地域で出す。** 提案では「住居系の案では常に」としたが、どの用途地域が
  日影規制の対象区域になりうるか（別表第四）を Claude Code が条文から決めて表にすることになるため
  （CLAUDE.md 1）、全用途地域で出す安全側を採った。対象区域外の建築物も対象区域に日影を生じさせる場合は
  規制を受ける（法56条の2第4項。0001 の未決定の論点に記載）ので、商業地域でも無関係とは言えない。
  用途地域で出し分けたい場合は、別表第四の対象用途の表を担当者の確認つきで `constants.py` に置いてから行う。
- **2 の向きは unknown。** 高さの最高限度の高度地区なら実際より大きく出るが、最低限度の高度地区や
  緩和型の地区計画もあり、一方向に決められないため。
- **2 は、いまのところ段の結果（API）にだけ出る。** 既存の画面と DXF は高度地区・地区計画の入力を持たないため。
  M03 で図面が段の結果から作られるようになれば、図面にも印字される。

## 影響

- **算定の数値は変わらない。** 回帰 13 ケースで、注記を除く全項目が相対誤差 1e-9 以内で一致することを確かめてから
  回帰結果を保存し直した（`tests/regression/README.md` 更新履歴）。
- DXF：足元の注記欄が 1〜2 行伸び、その上の図は平行移動しただけ。
- `solver/__init__.py` の中身が変わったので、「既存の算定ファイルが変わっていない」照合は、この修正後のタグ
  `m02-notes` を基準にする（`tests/test_m02_volume_stage.py`）。
